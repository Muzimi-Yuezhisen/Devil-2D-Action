# Noto Sans SC

- Font: `NotoSansSC-Regular.otf`
- Project: https://github.com/notofonts/noto-cjk
- License: SIL Open Font License 1.1
- License source: https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE

The font is bundled so Chinese UI text remains available in standalone builds.

## Character set

`ChineseCommon3500.txt` is the 3500 common simplified Chinese character list from
https://github.com/elephantnose/characters/blob/master/3500%E5%B8%B8%E7%94%A8%E6%B1%89%E5%AD%97.txt.
It is loaded at startup and pre-populated into the TMP dynamic atlas.
