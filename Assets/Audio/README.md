## Gothic audio refresh

Imported: 2026-09-13. All files below are CC0 and may be used commercially without attribution.

### Music

- Menu: TAD, `Vampire's Piano` — https://opengameart.org/content/vampires-piano
  - Project file: `menu_gothic_piano.mp3`
  - Purpose: restrained dark-fantasy piano for the gothic title screen.
- Gameplay: Sorth, `Foreboding Pixels` — https://opengameart.org/content/foreboding-pixels
  - Project file: `gameplay_gothic_loop.mp3`
  - Purpose: loop version; threatening pixel/gothic castle combat ambience.

### Combat sound effects

- remaxim, `3 Melee sounds` — https://opengameart.org/content/3-melee-sounds
  - Project files: `dark_sword_swing_01.wav`, `dark_sword_swing_02.wav`
  - Used for sword swing, dash and thrown-sword motion.
- Jordan Irwin / AntumDeluge, `Thwack Sounds` — https://opengameart.org/content/thwack-sounds
  - Project files: `dark_hit_01.wav`, `dark_hit_02.wav`, `dark_hurt.wav`, `dark_death.wav`, `dark_shard_impact.wav`
  - Used for dry physical hits and heavier impacts.

### Interface sound effects

- Robin Lamb, `UI Sound Effects` — https://opengameart.org/content/ui-sound-effects-button-clicks-user-feedback-notifications
  - Project files: `gothic_ui_click.ogg`, `gothic_menu_open.ogg`, `gothic_menu_close.ogg`, `gothic_victory.ogg`, `gothic_defeat.ogg`
  - Source samples originate from the public-domain VCSL and VSCO 2 CE libraries.

The older Kenney/ambient files remain in the repository as unused fallbacks; `AudioManager` routes every live cue to the refreshed set.
