模块总览

这个模块解决什么问题？

  • 让玩家用按键（L）打开/关闭技能树面板
  • 在树状 UI 上展示技能节点、连线和 Tooltip
  • 管理技能点消耗、前置节点、互斥分支
  • 解锁后将 Skill_DataSO 中的升级数据传给实际技能（如 Dash）

你可以把这个模块想象成三层：

层职责代表脚本
入口层谁打开 UI、谁管 Canvas 总开关Player.cs、UI.cs
业务层技能点、解锁规则、Tooltip 内容UI_SkillTree、UI_TreeNode、UI_SkillToolTip
布局层节点之间连线、位置自动排列UI_TreeConnectHandler、UI_TreeConnection

场景 Hierarchy 结构

Canvas ← UI.cs 挂在这里 ├── UI_SkillTree ← 默认 inactive，按 L 切换显示 │ ├── UI_TreeNode - Time echo ← 根节点，带 UI_TreeConnectHandler │ │ ├── Connection ← UI_TreeConnection（画线） │ │ └── Connection (1) │ ├── UI_TreeNode - Healing wisp │ └── …更多节点 └── UI_skillToolTip ← UI_SkillToolTip，与 SkillTree 同级 Player ← Player.cs 监听 L 键 └── …SkillManager / Skill_Dash ← 解锁后真正改技能行为
注意：UI_skillToolTip 是 Canvas 的兄弟，不是 UI_SkillTree 的子物体。Tooltip 脚本里用 GetComponentInParent<UI>() 找 Canvas 上的 UI 组件。

核心数据流

流程 1：打开技能树

按 L 键 → Input System: Player/ToggleSkillTreeUI.performed → Player.OnEnable 里注册的回调 → UI.ToggleSkillTreeUI() → skillTree.gameObject.SetActive(true/false) → 同时隐藏 Tooltip

流程 2：悬停节点

鼠标移入 UI_TreeNode → OnPointerEnter → 图标变 Hover 色 → UI_SkillToolTip.ShowToolTip(true, rect, node) → 显示名称、描述、解锁条件（技能点/前置/互斥）

流程 3：点击解锁

鼠标点击 UI_TreeNode → OnPointerDown → CanBeUnlocked()? ├─ 否 + isLocked → LockedSkillEffect() 文字闪烁 └─ 是 → Unlock() → 扣技能点、变白、锁互斥节点、连线变白 → skillManager.GetSkillByType(skillType) → Skill_Base.SetSkillUpgrade(upgradeData)

常见问题（对照你踩过的坑）

按 L 没反应 / NullReference

UI.Awake 必须用 GetComponentInChildren<UI_SkillTree>(true)，否则 inactive 的技能树找不到。

Direction 设 None 线还在

先保证 Connections 数组与 Connection Details 数量一致；若仍可见，在 DirectConnection 里对 None 加 SetActive(false)。

SetSkillUpgrade 类型报错

传 skillData.upgradeData（UpgradeData 对象），不是 .upgradeType（枚举）。

Tooltip NullReference

Tooltip 与 SkillTree 是 Canvas 下兄弟节点，用 GetComponentInParent<UI>() 和 GetComponentInChildren<UI_SkillTree>(true)。
