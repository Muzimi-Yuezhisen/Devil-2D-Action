模块总览

这个模块解决什么问题？

  • 让敌人在场景中自主巡逻（idle / move），用射线检测前方玩家
  • 发现或被打后进入战斗：追击、后撤、超时脱战回 idle
  • 进入攻击距离后播放攻击动画，动画结束回到战斗状态继续追击
  • 在攻击动画窗口内可被玩家弹反（Skeleton 实现 ICounterable），进入 stunned 击飞
  • 死亡时关闭状态机与碰撞，玩家死亡时所有敌人回到 idle

你可以把这个模块想象成三层：

层职责代表脚本
实体层参数、玩家检测、死亡/弹反窗口、订阅玩家死亡Enemy.cs、Enemy_Health.cs
状态层巡逻、战斗、攻击、眩晕、死亡的 Enter/Update 逻辑Enemy_*State.cs 系列
表现层动画事件：攻击判定、弹反窗口、状态结束信号EnemyAnnimationTriggers.cs
与模块 1 的关系：Enemy_Skeleton 在 Awake 里 new 各状态并 Start 时 stateMachine.Init(idleState)，与玩家侧模式一致。具体状态类继承 EnemyState → EntityState，由 StateMachine 每帧调用 Update。

核心流程

流程 1：巡逻发现玩家

Enemy_IdleState / Enemy_MoveState 每帧 Update → base Enemy_GroundedState.Update → enemy.PlayerDetected() 射线命中 Player Layer → stateMachine.ChangeState(battleState)

流程 2：战斗追击与攻击

Enter battleState → 缓存 player 引用；太近则后跳（retreatVelocity） Update battleState → 仍见到玩家则刷新战斗计时 → 超时 → idle → 距离 < attackDistance → attackState → 否则 battleMoveSpeed 朝玩家移动 Enter attackState → SyncAttackSpeed() → 动画 AttackTrigger 造成伤害 → CurrentStateTrigger → triggerCalled=true → 回 battleState

流程 3：弹反与受伤入战

攻击动画事件 EnableCounterWindow → canBeStunned=true + 攻击预警 VFX 玩家弹反 → Enemy_Skeleton.HandleCounter → stunnedState（击飞、关预警） 玩家攻击命中 → Enemy_Health.TakeDamage → base 扣血成功且伤害来源是 Player → TryEnterBattleState(damageDealer)

常见问题

敌人一直 idle 不追玩家

检查 playerCheck 朝向与 facingDir 是否一致；whatIsPlayer 是否包含 Player Layer；射线长度 playerCheckDistance 是否够远。巡逻时只有前方射线命中才进 battle。

战斗后立刻脱战回 idle

battleTimeDuration 从最后一次 PlayerDetected() 为真开始计时。玩家躲在墙后或跑到身后时，计时走完后会脱战。可适当加大 duration 或改进检测（如 360° 感知）。

贴脸不攻击或疯狂后跳

调 attackDistance 与 minRetreatDistance：后者应小于前者，否则 Enter 后跳后仍可能在攻击距离外反复横跳。

弹反无效

确认攻击动画上有 EnableCounterWindow / DisableCounterWindow 事件；Prefab 使用 Enemy_Skeleton 并实现 ICounterable；玩家弹反逻辑需读 CanBeCountered。

攻击动画滑步 / 速度不对

EnemyState.UpdateAnimationParameters 用 battleMoveSpeed/moveSpeed 同步 battleAnimSpeedMultiplier；攻击前 SyncAttackSpeed() 写入 attackSpeedMultiplier。检查 Animator 是否使用这两个参数。

死亡后还在动 / 还能被打

Enemy_DeadState.Enter 应关闭 anim、Collider 并 SwitchOffStateMachine()。若仍受伤，检查是否有多个 Collider 或状态机在别处被重新 Init。

玩家死后敌人仍追空气

Enemy.OnEnable 必须订阅 Player.OnPlayerDeath；对应 Player.EntityDeath 需触发该静态事件（见玩家状态机模块）。
