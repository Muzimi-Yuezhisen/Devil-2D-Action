模块总览

解决什么问题？

  • 背景随摄像机移动产生视差（远慢近快），增强纵深感
  • 背景移出屏幕时无缝循环拼接，实现横向无限延伸
  • 摄像机跟随玩家（Cinemachine，场景配置）
  • 关卡地面碰撞（Tilemap Collider，场景配置）

本模块只有 2 个脚本，大量工作在 Scene / Prefab Inspector 里完成。

每帧运行流程

FixedUpdate (ParallaxBackground) → 读 Camera.main.position.x → distanceToMove = 当前X - lastCameraPositionX → 更新 lastCameraPositionX → 算 cameraLeftEdge / cameraRightEdge（相机可见左右边界） → 对每个 ParallaxLayer: layer.Move(distanceToMove) // 按倍率平移 layer.LoopBackground(left, right) // 出屏则 ±imageWidth 拼接 Start (仅一次) → InitializeLayers() → 每层 CalculateImageWidth() → lastCameraPositionX = 相机当前X（防首帧跳动）

ParallaxBackground.cs

Assets/Scripts/Parallax/ParallaxBackground.cs · 挂在背景根物体上
MonoBehaviour

字段

名称类型作用
backgroundLayersParallaxLayer[]Inspector 配置的各视差层（Sky、Mid、Front…）
cameraHalfWidthfloat相机可见区域半宽 = orthographicSize × aspect
mainCameraCameraAwake 缓存 Camera.main
lastCameraPositionXfloat上一帧相机 X，用于计算本帧移动 delta

函数

函数何时调用做什么
Awake()物体初始化mainCamera = Camera.main；cameraHalfWidth = orthographicSize × aspect
Start()第一帧前InitializeLayers() 预计算每层图片宽度；lastCameraPositionX = 相机当前 X，避免首帧用 0 造成背景猛跳
FixedUpdate()固定物理帧（比 Update 更稳，减少抖动）算 distanceToMove 与相机左右边界；遍历 backgroundLayers 调用 Move + LoopBackground
InitializeLayers()Start 时foreach layer → layer.CalculateImageWidth()

ParallaxLayer（Serializable 类）

Assets/Scripts/Parallax/ParallaxLayer.cs · 不是 MonoBehaviour，嵌在 ParallaxBackground 数组里
Serializable

字段

名称类型作用
backgroundTransform该层背景的 Transform（带 SpriteRenderer）
parallaxMultiplierfloat相对相机的移动倍率：0=不动，0.5=半速，1=与相机同速
imageWidthOffsetfloat循环判定时边缘内缩，避免拼接缝（默认 10）
imageWidthfloat (private)CalculateImageWidth 后缓存的精灵宽度
imageHalfWidthfloat (private)imageWidth / 2，用于算左右边缘

函数

函数何时调用做什么
CalculateImageWidth()Start / InitializeLayers从 background 的 SpriteRenderer.bounds.size.x 取宽度；算 imageHalfWidth
Move(distanceToMove)ParallaxBackground.FixedUpdate 每帧background.position += Vector3.right × (distanceToMove × parallaxMultiplier)
LoopBackground(cameraLeftEdge, cameraRightEdge)Move 之后同帧算背景图左右边缘（带 offset）；若整图移出相机左侧则 position += imageWidth；移出右侧则 -= imageWidth，实现无缝循环
循环原理：背景是一张可平铺的长图（或重复图案）。当图的右边缘跑到相机左边外面，就把整张图向右平移一个 imageWidth，视觉上首尾相接。

场景 Hierarchy 建议

Background (ParallaxBackground 组件) ├── Background_Sky ← parallaxMultiplier 小（远景，几乎不动） ├── Background_Mid └── Background_Front ← multiplier 大（近景，动得快） Main Camera + CinemachineBrain CM vcam1 + CinemachineVirtualCamera → Follow: Player, LookAt: Player Grid / Tilemap + TilemapCollider2D (Layer: Ground)

Cinemachine 关键概念

项说明
Follow镜头跟踪的目标 Transform（Player）
Dead Zone玩家在小范围内移动时镜头不动，减少晃动
Orthographic Size正交相机「半高」，影响 ParallaxBackground 的 cameraHalfWidth 计算

常见问题

游戏开始背景突然跳一大段

lastCameraPositionX 默认 0，首帧相机动了 8 米就会按 8 米去移背景。必须在 Start 里初始化为 mainCamera.transform.position.x。

移动时天空和地面错位

只有部分 Sky 子图放进 backgroundLayers 时，未纳入的兄弟物不会 Move。做法：把 Left/Right 拼块都作为同一层 background 的子物体，或每层只用一个完整宽图。

为什么用 FixedUpdate 不用 Update？

与物理/相机跟随在同一节奏更新，减少帧率波动导致的背景抖动。若相机在 LateUpdate 移动，极端情况可能仍有轻微不同步，可按项目改为 LateUpdate 跟随相机。

循环出现黑缝

调 imageWidthOffset；确认 Sprite 素材左右能无缝拼接；检查 imageWidth 是否来自正确的 SpriteRenderer（子物体 vs 父物体）。
