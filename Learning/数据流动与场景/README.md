# 数据流动与场景

用「游戏里发生的一件事」串起脚本调用与数据从哪来、到哪去。  
**不参与 Unity 编译。** 浏览器打开 [index.html](./index.html)。

## 适合什么时候看

- 已经按模块 1–8 看过拆分讲解，想换一种方式把链路串起来
- 想搞清：按键之后谁检测、谁算伤害、Debuff 何时挂上、进游戏前要配什么

## 本页结构

1. **进游戏前配置** — SO、LayerMask、输入、Prefab、技能树节点  
2. **共用伤害管线** — GetAttackData → TakeDamage → Status / VFX  
3. **13 个场景** — 普攻、碎片、追踪、冲刺、弹反、敌我互殴、Debuff、解锁、Buff、传送/回溯、多重、开箱
