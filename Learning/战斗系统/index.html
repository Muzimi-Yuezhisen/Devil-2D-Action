模块总览

战斗系统把移动基类、攻击判定、生命值、元素状态、视觉反馈拆成多个 MonoBehaviour，挂在同一 GameObject（Player / Enemy）上，通过组件互相引用协作。

  • Entity — 物理移动、翻转、击退锁定、地面/墙壁射线、状态机每帧 Update
  • Entity_AnimationTriggers — 动画事件入口：转发状态触发器 / 调用 PerformAttack
  • Entity_Combat — OverlapCircle 找目标 → 读 Entity_Stats 算伤害 → IDamagable.TakeDamage → 施加元素状态 → 命中 VFX
  • Entity_Health — 闪避、护甲/抗性减免、扣血、回血、击退、死亡
  • Entity_StatusHandler — 冰冻减速、燃烧 DOT、感电充能落雷
  • Entity_VFX — 受击闪白、命中粒子、异常状态颜色闪烁
  • Player_Combat — 在基类之上增加弹反扫描（ICounterable）
  • Enemy_Health / Enemy_VFX — 敌人受击进战、弹反窗口预警
与属性系统的关系：伤害、护甲、闪避、元素抗性等数值全部来自 Entity_Stats（见模块 6）。本模块只负责「何时算伤害、如何传递、命中后发生什么」。

完整伤害流程图

【攻击发起】 Animator 播放攻击动画 → 动画事件 AttackTrigger() [Entity_AnimationTriggers] → Entity_Combat.PerformAttack() 【目标检测】 PerformAttack() → GetDetectedColliders() Physics2D.OverlapCircleAll(targetCheck, targetCheckRadius, whatIsTarget) → 遍历每个 Collider2D 【对每个目标】 → target.GetComponent<IDamagable>() → 若无 IDamagable → continue 跳过 【伤害计算 — 攻击方 Entity_Stats】 → stats.GetElementalDamage(out element, 0.6f) // 元素伤害 + 主元素类型 → stats.GetPhysicalDamage(out isCrit) // 物理伤害 + 是否暴击 【受击处理 — IDamagable.TakeDamage】 Entity_Health.TakeDamage(damage, elementalDamage, element, transform) ├─ isDead == true → return false ├─ AttackEvaded() → Random(0,100) < GetEvasion() → return false ├─ 攻击者 Entity_Stats.GetArmorReduction() → armorReduction ├─ 受击者 GetArmorMitigation(armorReduction) → mitigation │ physicalDamageTaken = damage × (1 - mitigation) ├─ 受击者 GetElementalResistance(element) → resistance │ elementalDamageTaken = elementalDamage × (1 - resistance) ├─ TakeKnockback(damageDealer, physicalDamageTaken) │ → CalculateKnockback / CalculateDuration │ → entity.ReceiveKnockback(knockback, duration) │ → KnockbackCo: isKnocked=true, 设 rb 速度, 等待, 清零, isKnocked=false ├─ ReduceHealth(physical + elemental) │ → entityVfx.PlayOnDamageVfx() // 受击材质闪白 │ → currentHealth -= damage │ → UpdateHealthBar() │ → currentHealth <= 0 → Die() → isDead=true → entity.EntityDeath() └─ return true 【敌人专用 — Enemy_Health override】 base.TakeDamage 命中后 → damageDealer 有 Player 组件 → enemy.TryEnterBattleState(damageDealer) 【元素状态 — 攻击命中且 element != None】 Entity_Combat.ApplyStatusEffect(target.transform, element) → target.GetComponent<Entity_StatusHandler>() → CanBeApplied(element) 检查是否可挂状态 ├─ Ice → ApplyChillEffect(duration, chillSlowMultiplier) │ → 冰抗减时长 → ChilledEffectCo → SlowDownEntity + PlayOnStatusVfx ├─ Fire → ApplyBurnEffect(duration, fireDamage × fireScale) │ → 火抗减总伤 → BurnEffectCo → 每秒 2 tick DOT └─ Lightning → ApplyElectrifyEffect(duration, lightningDamage × lightningScale, charge) → 雷抗减充能 → 累加 currentCharge → charge >= maximumCharge → DoLightningStrike + StopElectrifyEffect → 否则 ElectrifyEffectCo → PlayOnStatusVfx，超时清 charge 【命中 VFX — targetGotHit == true】 → vfx.UpdateOnHitColor(element) // 改攻击方命中粒子颜色 → vfx.CreateOnHitVFX(target, isCrit) // 在目标位置生成 hit/crit 预制体 【弹反流程 — 独立于 PerformAttack】 Player 按 CounterAttack → Player_CounterAttackState.Enter() → Player_Combat.CounterAttackPerformed() → Overlap 内找 ICounterable 且 CanBeCountered → counterable.HandleCounter() // 例：Enemy_Skeleton → stunnedState 敌人攻击动画事件 EnableCounterWindow → canBeStunned=true + Enemy_VFX.EnableAttackAlert(true) 【非战斗 IDamagable — Object_Chest】 TakeDamage → PlayOnDamageVfx + 开盖动画 + Rigidbody2D 弹飞（不算护甲/不扣血）

FAQ

攻击何时真正造成伤害？

不在按键瞬间，而在动画事件 AttackTrigger 触发帧。Animator _clip 里须添加与 Entity_AnimationTriggers.AttackTrigger 同名的事件。

TakeDamage 返回 false 时还有什么发生？

不扣血、不击退、不播放命中 VFX（PerformAttack 里 targetGotHit 为 false）。闪避时 Console 会 Log 目标名 evaded。

重击（Heavy Knockback）如何判定？

仅看护甲减免后的物理伤害占最大生命比例是否 > heavyDamageThreshold（默认 30%）。元素伤害不参与重击判定。

为什么冰冻能叠、燃烧不能？

CanBeApplied：仅 Lightning 在已感电时仍返回 true；Fire/Ice 要求 currentEffect == None。燃烧进行中再次火攻击不会刷新（需等 BurnEffectCo 结束）。

感电 charge 和 Burn tick 伤害吃抗性吗？

ApplyBurnEffect / ApplyElectrifyEffect 入口已用对应抗性缩减传入的总伤/charge；BurnEffectCo 内每 tick 的 ReduceHealth 不再二次计算抗性。落雷 DoLightningStrike 的 damage 已是缩放后数值。

击退期间为什么无法移动？

KnockbackCo 期间 isKnocked=true，SetVelocity 直接 return。击退结束才恢复 State 对速度的控制。

弹反判定窗口在哪打开？

敌人攻击动画里 EnableCounterWindow 事件 → Enemy.EnableCounterWindow(true) + Enemy_VFX.EnableAttackAlert(true)。窗口结束或进入 Stunned 时关闭。玩家须在窗口内进入 CounterAttackState 且 Overlap 碰到 CanBeCountered 的敌人。

Entity_VFX 暴击预制体是否写反了？

当前代码 CreateOnHitVFX 中 isCrit ? hitVFX : critHitVFX，命名上与直觉相反。文档按现有代码行为记录；若表现不对请检查此三元表达式。

宝箱为什么需要 Entity_VFX 和 IDamagable？

复用同一套攻击检测（Overlap + IDamagable），无需单独写「开箱」碰撞逻辑。受击只播 VFX + 物理反馈，不走 Entity_Health。

需要改伤害公式去哪改？

攻击方：Entity_Stats.GetPhysicalDamage / GetElementalDamage。防御方：GetArmorMitigation / GetElementalResistance / GetEvasion。本模块 Entity_Health.TakeDamage 只调用这些 API。
