模块总览

本模块已完成的内容：

  • Player 上的运行时技能：Skill_Dash、Skill_Shard（继承 Skill_Base）
  • 技能树解锁写入：upgradeType + cooldown + damageScaleData
  • upgradeType == None 视为未解锁，不能释放
  • Dash：状态机位移 + OnStartEffect / OnEndEffect（已接线）
  • Time Shard：Spell 键 → TryUseSkill → 生成 SkillObject_Shard → 爆炸伤害
  • Shard 进阶：追踪、多重充能、传送、生命回溯
分工：模块 7 = 树 UI 与解锁；本模块 = 运行时技能与生成物；模块 2 = Dash 位移状态；模块 5/6 = AttackData 伤害结算。

四层架构

【配置】Skill_DataSO + UpgradeData（挂在 UI_TreeNode） cost / unlockedByDefault / skillType / upgradeType / cooldown / damageScaleData ↓ Unlock → SetSkillUpgrade 【运行时技能】Skill_Base → Skill_Dash / Skill_Shard（Player 子物体） CD、当前分支、伤害缩放缓存 ↓ Instantiate / CreateRawShard 【技能生成物】SkillObject_Base → SkillObject_Shard（场景 Prefab） 检测敌人、爆炸、可选追踪 ↓ GetAttackData(damageScaleData) 【战斗结算】AttackData → TakeDamage + ApplyStatusEffect（模块 5）

流程 A：解锁

UI_TreeNode.Start → 若 unlockedByDefault → Unlock() 或 玩家点击且 CanBeUnlocked → Unlock() → GetSkillByType(skillData.skillType) → SetSkillUpgrade(upgradeData) upgradeType / cooldown / damageScaleData 整份写入
易错：根技能（如 Quick dash）若 unlockedByDefault，其 upgradeType 必须是 Dash 等有效值，不能是 None，否则开局会把技能写成「未解锁」。解锁是整份替换，高级节点会覆盖基础节点的 CD 与 damageScale。

流程 B：Dash

任意 PlayerState.Update → Dash 键 && CanDash() → dash.CanUseSkill()（非 None、非 CD） → 非贴墙、非已在 dashState → SetSkillOnCooldown() + ChangeState(dashState) Player_DashState.Enter → dash.OnStartEffect() // Clone / RawShard 按升级 → 关重力、定方向、计时 Player_DashState.Exit → dash.OnEndEffect() // Arrival 类升级再生成 → 恢复重力

流程 C：Time Shard（Spell 键）

Player.OnEnable：Spell.performed → shard.TryUseSkill() → CanUseSkill() 失败则 return → 按 upgradeType 精确匹配走一个分支： Shard → CreateShard + CD Shard_MoveToEnemy → CreateShard + 追踪 + CD Shard_Multicast → 扣充能 + 追踪；充能协程按 cooldown 回复 Shard_Teleport → 无碎片则放置；有碎片则换位爆炸并 CD Shard_TeleportHpRewind → 放置时记血量%；换位时回血并 CD CreateShard → Instantiate Prefab → SetupShard(this) → Invoke(Explode, GetDetonateTime()) → 触碰 Enemy 或到时 → Explode → DamageEnemiesInRadius → AttackData → TakeDamage / 状态

伤害缩放（与普攻共用管道）

技能爆炸与普攻都走 Entity_Stats.GetAttackData(DamageScaleData) → AttackData。

来源缩放配置
普攻 Entity_CombatInspector 上的 basicAttackScale（场景常为 physical=1, elemental≈0.4）
技能碎片解锁写入的 Skill_Base.damageScaleData（来自 SO UpgradeData）
AttackData(stats, scaleData) physical = GetPhysicalDamage(out isCrit, scaleData.physical) elemental = GetElementalDamage(out element, scaleData.elemental) effectData = ElementalEffectData(stats, scaleData) // burn = fireDamage × burnDamageScale // shock = lightningDamage × shockDamageScale // chill 时长/减速、shockCharge 直接来自 scaleData

详见 模块 5、模块 6。

常见问题

开局冲刺不能用？

检查 Quick dash 的 upgradeType 是否为 Dash。若为 None，unlockedByDefault 会在 Start 把冲刺写成未解锁。

解锁 Irritated 后 CD 不对？

高级节点 SO 的 cooldown 会整份覆盖。核对 Irritated 的 skillType=TimeShard、upgradeType=Shard_MoveToEnemy、cooldown 数值。

未解锁 Shard 却能按 F？

场景里 Skill_Shard 的 upgradeType 不要预填 Shard；应保持 None，等树解锁写入。

Dash 升级出碎片不伤人？

RawShard 用的是当前 Skill_Shard.damageScaleData。若尚未解锁任何 Time Shard 节点，scale 可能为空/默认，需先解锁带 damageScale 的 Shard 技能，或给 Dash 升级 SO 也配 scale（当前设计读的是 shard 组件上的缓存）。

为什么升级不能叠加？

Unlocked 是精确相等；树用 conflictNodes 互斥。一次只保留一个 upgradeType。
